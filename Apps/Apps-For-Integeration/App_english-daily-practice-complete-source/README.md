# English Automaticity — Daily Practice

Complete standalone source for the English Daily Practice preview.

## Run

Open `index.html` in Chrome, Edge, or Firefox. No installation, server, account, or internet connection is required.

## Included

- responsive three-column Daily Practice layout,
- seven learning activities grouped into three phases,
- progress ring and daily status cards,
- flexible 15, 30, and 45-minute plan controls,
- keyboard-visible buttons and semantic page regions,
- embedded CSS, SVG-like CSS mascot, and JavaScript interactions.

All frontend code, styles, assets, and interactions are contained in `index.html`.

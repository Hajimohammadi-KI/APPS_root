# PDF Reader visual files

- `00-foundation.css` — reader colors and base behavior
- `01-reader-shell.css` — top bar, sidebar and toolbar
- `pages/document-viewer.css` — PDF canvas, text layer and annotations
- `pages/study-panel.css` — AI, translation and notes panel
- `components/selection-menu.css` — contextual highlight and comment menu
- `components/settings-dialog.css` — reader settings and connected services
- `components/focus-timer.css` — focus timer
- `90-responsive.css` — responsive layouts
- `91-accessibility.css` — reading ruler

All files are loaded in order by `../globals.css`.

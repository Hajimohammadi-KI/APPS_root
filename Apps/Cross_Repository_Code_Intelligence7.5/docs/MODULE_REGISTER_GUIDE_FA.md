# راهنمای ساده صفحه Modulregister

این صفحه برای این است که تمام «ماژول‌های پروژه» را در یک لیست ببینی و بدانی هرکدام در چه وضعیت پژوهشی هستند.

## این صفحه دقیقا چه می‌گوید؟

هر ردیف یک ماژول است. کنار نام ماژول یک نقطه رنگی می‌بینی:

- آبی: CORE
- سبز: BASELINE
- نارنجی: EXPERIMENT

## معنی وضعیت‌ها

- CORE: جزء اصلی سیستم است و باید وارد محصول نهایی شود.
- BASELINE: برای مقایسه علمی استفاده می‌شود تا بفهمی روش اصلی واقعا بهتر است یا نه.
- EXPERIMENT: آزمایشی است و تا قبل از Pilot جدا نگه داشته می‌شود.

## چطور از این صفحه استفاده کنم؟

1. از بالای صفحه، فیلتر Alle Module را روی نوع موردنظر بگذار.
2. یک ردیف را باز کن.
3. سه چیز را چک کن: هدف ماژول، معیار موفقیت، و خروجی قابل تحویل.
4. اگر ماژول CORE است، اولویت روزانه بده.
5. اگر BASELINE است، نتیجه را فقط با معیار مقایسه‌ای ثبت کن.
6. اگر EXPERIMENT است، آن را مستقیم وارد هسته اصلی نکن.

## ترتیب ساده تصمیم‌گیری

- اگر امروز خروجی محصول می‌خواهی: CORE
- اگر امروز اعتبار علمی می‌خواهی: BASELINE
- اگر امروز ایده جدید را تست می‌کنی: EXPERIMENT

## تعریف کوتاه هر ردیف

هر ردیف باید 4 پاسخ روشن داشته باشد:

1. این ماژول چه مسئله‌ای را حل می‌کند؟
2. خروجی قابل تحویل امروز چیست؟
3. با چه معیار/تستی می‌گویی موفق شد؟
4. در پایان به کدام Phase نقشه راه وصل می‌شود؟

اگر بخواهی، نسخه بعدی را طوری تنظیم می‌کنم که همین توضیح‌ها داخل خود صفحه کنار هر ردیف دیده شود.

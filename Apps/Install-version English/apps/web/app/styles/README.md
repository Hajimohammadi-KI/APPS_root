# English Automaticity visual files

All application styling is loaded through `../globals.css`.

## Page styles

- `pages/dashboard.css` — Home and progress story
- `pages/daily-practice.css` — Today's Practice and daily steps
- `pages/conversation-studio.css` — Conversation Studio, coach, chat and evaluation
- `pages/grammar.css` — Grammar topic list and practice area
- `pages/resources.css` — Learning resources
- `pages/settings.css` — Settings screen rows
- `pages/learning-evidence.css` — Errors and saved audio cards

## Shared styles

- `00-foundation.css` — design tokens, colors and base elements
- `01-legal-pages.css` — privacy and support pages
- `02-app-shell.css` — sidebar, top bar, navigation and page headings
- `components/install-dialog.css` — install and update dialog
- `90-responsive.css` — shared tablet and mobile rules
- `91-accessibility.css` — reading ruler, neuroinclusive options and Persian word help
- `99-visual-refresh-overrides.css` — newest cross-page visual refinements

When redesigning one screen, begin with its file under `pages/`. Shared navigation and layout belong in `02-app-shell.css`; global colors and typography belong in `00-foundation.css`.

# Integrated Skills Path

## Purpose

Integrated Skills Path is the original four-skills curriculum inside English
Automaticity. It replaces the former branded section and does not require a
commercial textbook, copied exercise, external Drive folder, or proprietary
media file.

The learner practises listening, speaking, reading, and writing from A1 to C2.
The target is usable, retained language—not lesson consumption or a streak.

## Curriculum contract

- Six CEFR levels: A1, A2, B1, B2, C1, and C2.
- Four independently written real-life units per level (24 units total).
- Four skill paths per unit (96 paths total).
- Seven evidence stages per skill path (672 stage records total).
- A level foundation with grammar, vocabulary, pronunciation, and communicative
  outcomes.
- A level gate based on completed performance evidence and delayed recall.

Every skill follows the same automaticity ladder:

1. Understand
2. Recognise
3. Recall
4. Supported use
5. Independent use
6. Transfer to a new situation
7. Delayed review

Completing a transfer schedules the delayed review for the following day.
Opening a lesson alone never counts as mastery.

## Daily learning design

The screen shows one current action and offers two modes: a normal 12-minute
mission and a one-step rescue mission. Neither mode uses a countdown timer.
Rest and illness do not erase progress.

The interface includes large controls, strong contrast, spoken instructions,
model playback, speech-to-text, low-stimulation presentation, short prompts,
and local save-and-resume. Spelling does not block a practice stage, while the
learner still produces evidence before completing it.

## Persistence and backups

Current level, unit, skill, stage, responses, completion timestamps, and review
dates are stored in the main local application state. They therefore travel
with the app's existing JSON backup/export and import process. Existing users
who do not yet have this state receive a safe A1 starting point without losing
other progress, settings, notes, audio, or assessment history.

## Content provenance

All unit titles, outcomes, texts, prompts, vocabulary sets, progression rules,
and exercises in this path are authored for English Automaticity. Public and
internal application code contains no former product name, direct textbook
source link, or copied question bank. The quarantined prior implementation is
not required by this application and was intentionally not copied back into
the authoritative source.

# DeutschFlow visual files

- `00-foundation.css` — Farben, Typografie und Grundelemente
- `pages/dashboard.css` — Startseite, Tagesaufgaben und Fortschritt
- `90-responsive.css` — Tablet- und Mobilansicht
- `91-accessibility.css` — Leselineal und neuroinklusive Hilfen
- `99-visual-refresh-overrides.css` — neueste visuelle Überarbeitung für Lernseiten

`../globals.css` is the single ordered entry point. Route components that use Tailwind utility classes remain beside their page component; shared custom CSS belongs here.

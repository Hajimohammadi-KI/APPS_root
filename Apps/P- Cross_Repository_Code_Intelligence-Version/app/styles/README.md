# Cross Repository Tracker visual files

- `00-foundation.css` — design tokens and base elements
- `01-app-shell.css` — header, sidebar and navigation
- `pages/tracker.css` — plan, phases, weeks, days, tasks, forms and integrations
- `pages/dashboard.css` — current home dashboard and learning journey
- `components/hover-help-and-course.css` — Persian hover help and course banner
- `90-responsive.css` — tablet and mobile layouts
- `91-accessibility.css` — global reading ruler

Route-specific tools remain independently styled in `app/pdf-reader`, `app/settings`, and `app/nlp-lab`.

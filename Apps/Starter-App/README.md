# APPS_root Starter

Double-click `START-APPS.cmd` in the repository root.

The Starter uses the existing Bun/Node runtimes and existing production builds. It does not install or package the applications. It starts only services that are not already listening and opens the current runtime URL.

The Starter itself listens on 4300.

Included applications:

- English Automaticity: web 3202, API 4201
- Deutsch Automaticity: web 3210, API 4210
- Cross Repository Tracker: web 4312, API 4313
- Settings: 4323
- PDF Reader: 4322

Runtime logs are written to `Apps/Starter-App/logs`.

# پرامپت مادر سه صفحهٔ گرامر

این قالب از چیدمان سه تصویر استخراج شده است. رنگ سبز و عنوان‌های نادرست دستوری تصاویر، از جمله «Genitiv» برای تمرین‌های غیراضافی، جزو الگو نیستند. هر مجموعه فقط یک تصمیم دستوری را تمرین می‌دهد.

```text
ROLE
You are an instructional designer and English and German curriculum specialist. Create
printable A4 worksheets for adults, aimed at accurate, independent production.

INPUTS
TARGET LANGUAGE: {{English / German}}
TOPIC: {{GRAMMAR_TOPIC}}
LEVEL: {{CEFR_LEVEL}}
INSTRUCTION LANGUAGE: {{Target language only / Target language + Persian}}
TARGET DECISION: {{ONE_OBSERVABLE_DECISION}}
COMMON ERROR: {{ONE_ERROR_CAUSE}}
KNOWN PREREQUISITES: {{FORMS_TO_KEEP_FIXED}}

Produce exactly three learner pages, in this order:

PAGE 1: LEARN
Indigo header with title and subtitle. Three aligned contrast cards with line
icons, short blue labels and correct examples in the target language. A sand decision box:
signal → grammatical choice → resulting form. A compact reference table.
Two short decisions with generous answer space and a separate WHY column.

PAGE 2: PRACTICE
The same header, palette, typography and card system. Two guided drills,
one explicit transformation that changes one signal, one reconstruction from
memory with a model that can be covered, and three oral response prompts with
3–5 seconds per prompt. Give every item an answer field and a WHY field.
The learner explains WHY after the timed response, without time pressure.

PAGE 3: ASSESS
Two clearly labelled error-correction items, one personal production task,
an error log (my error | correction | root cause / trigger), and a bottom
review strip with empty checkboxes: Tag 1, Tag 3, Tag 7, Tag 14 for German;
Day 1, Day 3, Day 7, Day 14 for English.

PEDAGOGICAL CONSTRAINTS
1. Keep ONE decision throughout all three pages. Hold prerequisites fixed.
2. Present rules as decision chains, never as long paragraphs.
3. Include WHY space for every exercise, including oral and personal work.
4. Reconstruction must require writing after covering the model.
5. Transformation must specify exactly what changes and what stays fixed.
6. Oral prompts must be answerable in 3–5 seconds; do not time explanations.
7. Ask for a real example from the learner's life.
8. Review marks record practice, not proof of mastery.
9. All model language must be correct. Incorrect target-language sentences appear ONLY inside
   labelled correction tasks. For style or meaning, label a grammatically
   possible sentence as unsuitable for the stated context, not ungrammatical.
10. Keep answer lines at least 9 mm high. Keep English and German writing LTR;
    isolate Persian instructions RTL. Do not mix four error types in one item.

VISUAL CONTRACT
A4 portrait, 210 × 297 mm, 10 mm print margins. Warm paper #FAF8F4;
navy-charcoal text; primary indigo #3D5A9E; sand panels #EFE7DA;
sparingly use coral #D96B5A for correction marks only. NO GREEN.
Use rounded cards, thin light borders, quiet shadows, crisp sans-serif type,
simple indigo geometric line icons. No people, clip art or emoji.
Header: white bold title on indigo, then a smaller subtitle.
Rhythm: header → grouped cards → sand rule/recall panel → compact table or
response grid → bottom strip. The appearance must stay consistent by topic.

ANSWER KEYS
For each page supply a separate, clearly labelled answer key:
correct answer | root cause | trigger word | error category | contrast example.
For personal writing provide review criteria and a possible example, not a
single supposedly exhaustive correct answer. Keep solutions hidden until
self-check. Print keys separately so learner sheets remain exactly 3 pages.

DIGITAL INPUT
Every answer and WHY field supports keyboard input and device handwriting.
Use an expandable pen pad with pressure-aware Pointer Events, undo, a stroke
eraser and clear. Preserve typed text and ink separately when switching pages,
topics, instruction languages or screen sizes. Save drafts locally and show
saving failures honestly. Handwriting remains ink, not an OCR transcription.
Keep an accessible keyboard alternative. Do not grade ink automatically.
Provide separate exports: three blank A4 learner pages; answer keys; learner
answers with all text and ink. Allow extra pages for long learner answers.

PRE-PRINT CHECK
Check every target-language sentence, every causal explanation and transformation.
Verify three actual A4 pages, all writing lines, readable type, no clipped
content, no green, no solution leakage and no claims of demonstrated mastery.
```

در برنامه، محتوای هر قاعده جداگانه تعریف می‌شود و همین قالب مشترک آن را نمایش می‌دهد. تعداد صفحات یا علامت مرور به‌تنهایی نشان‌دهندهٔ خودکارشدن مهارت نیست.

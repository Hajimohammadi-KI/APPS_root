Vertical Slice واقعی در English و Deutsch

در حال انجام
برآورد: ۱ sprint · وابستگی: G0 · Issue: #14

تبدیل قرارداد pure core به مسیر واقعی یادگیری در هر دو اپ: یک واحد authored و human-reviewed در سطح B1 برای هر زبان؛ مسیر کامل content → daily plan → learner response → evaluation → evidence → local event؛ یک تلاش نوشتاری و یک تلاش گفتاری با صدای واقعی.

Conversation Studio: Listen/Recall → Record → Replay → Review transcript → Correct → Improve → Save. transcript و evaluation واقعی؛ هیچ پاسخ hard-coded یا demo evidence پذیرفته نیست.

معیار خروج
  • E2E برای EN و DE نشان دهد با re-record، evidence قبلی باطل می‌شود
  • speaking بدون audio معتبر، mastery-eligible نشود
  • پاسخ اشتباه، completion یا تایمر ۶۰ ثانیه status automatic ندهد
  • delayed recall و novel transfer به‌صورت event جدا قابل ثبت باشند
  • خطای provider با وضعیت unavailable دیده شود، نه موفقیت جعلی
پیشرفت تأییدشدهٔ فعلی
  • PR آلمانی #13 پس از typecheck، lint، unit/integration، installer، schema، build و ۱۵ E2E merge شد؛ ۲ تست اختیاری PWA skip شدند
  • learning-core برای هر دو زبان ledger محلی نسخه‌دار می‌سازد و speaking بدون audio را unverified نگه می‌دارد
  • commit a0e5642 خروجی هر دو اپ را به envelope شامل learnerState و learningEvidence ارتقا داد؛ E2E دانلود واقعی هر دو زبان پاس شد
  • build تولیدی هر دو اپ پاس شد و لینک‌های محلی دوباره HTTP 200 هستند

N/A — هنوز به‌اندازهٔ کافی تأیید نشده: microphone واقعی و provider خارجی. مسیر B1 دو زبان، invalidation پس از re-record و eventهای مستقل delayed recall / novel transfer هنوز باید یکجا در Issue #14 اثبات شوند؛ بنابراین G1 بسته نشده است.

پایلوت رضایت‌محور و Analytics

در انتظار G5
برآورد: ۴ تا ۸ هفته جمع‌آوری داده · وابستگی: G5 · Issue: #10

ابتدا internal، سپس cohort کوچک با رضایت آگاهانه؛ rollout ترتیبی control → shadow → opt-in intervention. اگر فقط یک کاربر یا یک دستگاه وجود دارد، فقط descriptive local analytics مجاز است؛ Kaplan-Meier، AUC یا ادعای cohort ساخته نمی‌شود.

تصمیم Go/No-Go — Intervention فقط وقتی گسترش می‌یابد که
  • learning outcome بدتر نشده باشد و false positive افزایش معنادار نداشته باشد

  • consent، export و deletion کار کنند
  • اثر برای حداقل یکی از delayed recall یا novel transfer دیده شود
